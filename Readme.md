# Individual Coding Lab — Grade Evaluator & Organizer

## Files
- grade-evaluator.py — validates and evaluates student grades
- organizer.sh — archives grades.csv and resets the workspace
- grades.csv — sample data (columns: assignment,category,weight,score)

## Running the Python application
1. Make sure grades.csv is in the same folder.
2. Run: python3 grade-evaluator.py

## Running the shell script
1. chmod +x organizer.sh
2. ./organizer.sh
